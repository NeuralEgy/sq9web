# square9-web

موقع **Square9 Developments** العام — مشروع Aurora Palace، الغردقة.
ريبو منفصل تمامًا عن `square9Agent` (ده موقع عام، وده نظام داخلي).

```bash
npm install
npm run dev     # http://localhost:3032
npm run build
npm test
```

## قاعدة الملف ده

🔴 **ممنوع أي سعر أو خطة سداد أو حالة وحدة أو رقم عائد على الموقع.** البيانات دي
مش منشورة ولا متسلّمة من العميل. كل حقيقة معروضة لازم تكون في
[`src/data/project.ts`](src/data/project.ts)، واللي مش منشور بيتسجّل تحت
`NOT_PUBLISHED` والموقع بيعرض حجز زيارة مكانه.

الرقم الوحيد المنشور عن السداد: **١٠٪ مقدم**.

## اللغة

الموقع **إنجليزي بلغة واحدة**، مسارات نضيفة بلا بادئة لغة. النسخة العربية
(`/ar` + ميدلوير + قاموسين) كانت موجودة لحد كوميت `e3559af` — ترجع بـrevert
لو اتطلبت.

## الشكل

اتجاه **Warm Light**: ألوانه مسحوبة من رندرات المشروع نفسها (رمل · تراكوتا ·
ذهب الغروب)، خط Cormorant Garamond للعناوين وInter للنص، تخطيط مجلة غير
متماثل. الاتجاه التاني (أسود تحريري) كان في `/preview/a` واتشال بعد الاختيار.

التوكنز في [`tailwind.config.ts`](tailwind.config.ts) والنصوص كلها في
[`src/content/copy.ts`](src/content/copy.ts) — عشان الكلام يتعدّل من غير ما
حد يفتح مكوّن React.

## الصور

🔴 **بس ٧ صور بتخص Aurora Palace فعلًا** — اللي تحت `public/images/aurora/`.
الصور اللي كانت على موقعهم الحالي باسم `community/lifestyle/interior/amenities`
صور ستوك عامة (واحدة منها صورة مموّهة لست شايلة ورد) — اتشالت.

**مفيش ولا صورة وحدة من جوّه، ولا مخططات.** عشان كده قسم الوحدات نصّي
بالكامل — حط صورة ستوك تحت عنوان «Studio» يعني توحي للمشتري إنها الشقة.

## قرارات مستنية العميل

1. **مستخدم القاعدة `sq9_site`** — السكربت جاهز في [`db/role-site.sql`](db/role-site.sql)
   بس لسه ما اتشغّلش على الـVPS. من غيره الفورم بيرد على العميل «كلّمنا على
   واتساب» بدل ما يسجّل.
2. **إحداثيات مجاويش** — اتشالت من الكود ومن البيانات المنظّمة. تتأكد من
   العميل قبل أي خريطة أو JSON-LD.
3. **صور الوحدات والمخططات** — لو اتسلّمت، قسم الوحدات يتغيّر.

## النشر

**ما اتنشرش، ومش هيتنشر من غير إذن العميل.**
[`ecosystem.config.cjs`](ecosystem.config.cjs) جاهز: المنفذ 3032 على
`127.0.0.1` (3030 للـagent و3031 للبورتال)، وNginx قدامه. الأسرار في
`/opt/square9-web/.env.local` مش في الريبو.
