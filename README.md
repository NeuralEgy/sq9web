# square9-web

موقع **Square9 Developments** العام — مشروع Aurora Palace، الغردقة.
ريبو منفصل تمامًا عن `square9Agent` (ده موقع عام، وده نظام داخلي).

```bash
npm install
npm run dev     # http://localhost:3032
npm run build
```

## قاعدة الملف ده

🔴 **ممنوع أي سعر أو خطة سداد أو حالة وحدة على الموقع.** البيانات دي مش منشورة
ولا متسلّمة من العميل. كل حقيقة معروضة لازم تكون في `src/data/project.ts`،
واللي مش منشور بيتسجّل تحت `NOT_PUBLISHED` والموقع بيعرض حجز زيارة مكانه.

الرقم الوحيد المنشور عن السداد: **١٠٪ مقدم**.

## صور

⚠️ **مفيش صور من العميل.** الهيرو تدرّج لوني مش صورة — بيفتح فورًا على الموبايل،
ولما الصور توصل بتتحط مكانها من غير ما يتغيّر أي حاجة تانية.

## وزن الصفحة (مقيس، مش تقديري)

صفحة `/ar` كاملة: **283 كيلوبايت** في **14 طلب** — 109 جافاسكريبت · 145 خطوط ·
24 HTML · 6 CSS. مفيش صور، ومفيش جافاسكريبت للهيدر ولا التنقّل؛ الجزء التفاعلي
الوحيد هو فورم الحجز.

🔴 **الخطوط أتقل من الجافاسكريبت.** كل وزن خط = ملفين (عربي + لاتيني) ≈ 48 كيلوبايت،
فالمشروع شايل تلات أوزان بس (400 · 600 · 700). لو حد زوّد وزن رابع، وزن الصفحة
بيزيد الربع.

## النشر

**ما اتنشرش، ومش هيتنشر من غير إذن العميل.** `ecosystem.config.cjs` جاهز:
المنفذ 3032 على `127.0.0.1` (3030 للـagent و3031 للبورتال)، وNginx قدامه.
الأسرار في `/opt/square9-web/.env.local` مش في الريبو.

## قرارات مستنية العميل

1. **مستخدم القاعدة `sq9_site`** — السكربت جاهز في `db/role-site.sql` بس لسه ما اتشغّلش
   على الـVPS. من غيره الفورم بيرد على العميل «كلّمنا على واتساب» بدل ما يسجّل.
2. **اسم الريبو على GitHub** — قبل أي push.
3. **إحداثيات مجاويش** في `src/data/project.ts` تقريبية، فاتشالت من البيانات المنظّمة
   عن قصد. تتأكد من العميل قبل ما تتحط في JSON-LD أو أي خريطة.
